flymath

An upload-an-image, math-symbols-burst-out-of-it web tool — in 13 implementations produced by different coding models from the same requirement.

纯前端小工具：选一张背景图，让数学符号从画面中心向四周飞散，导出 PNG 或 GIF。这个页面收录同一需求交给多个模型后拿到的 13 份实现——它们不是迭代关系，每一版坏掉的方式都不一样。

Start with math-explosion-html-v2.html or mathfx-qwen.html — zero dependencies, so they work without a network. The two .tsx files are React components; opening them in a browser shows source text, which is expected — there is no build config in this repo. Attribution of each file to a model comes from the filename and the model's own note inside the file; there is no original prompt transcript kept, so these are "several models handed the same requirement", not "the same prompt verbatim". No demo images are shipped: the originals were generated from real photographs.
